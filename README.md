# Thurhub

# instalar versão C

```bash
git clone https://github.com/ilzacoelhomt73-cmyk/thurhub.git && cd thurhub && gcc v1/thurhub.c -o thurhub -lcrypto && ./thurhub
```

# instalar versão python (V2)

# para termux

```bash
pip install requests && git clone https://github.com/ilzacoelhomt73-cmyk/thurhub.git && cd thurhub && cd v2 && python3 thurhub.py
```

# para debian 

```bash 
pip install requests --break-system-packages && git clone https://github.com/ilzacoelhomt73-cmyk/thurhub.git && cd thurhub && cd v2 && python3 thurhub.py
```
